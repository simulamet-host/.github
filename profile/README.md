# SimulaMet — Department of Holistic Systems (HOST)

The **Department of Holistic Systems (HOST)** at [SimulaMet](https://github.com/SimulaMet) conducts research to address real-world challenges in distributed systems, using a holistic approach that encompasses all components of the system.

Researchers within HOST work on complex systems made up of many integrated components, conducting basic research, experimental prototyping, and running experiments in intended real-world environments.

> **Focus:** System performance, resource consumption, scalability, and quality of service in complete, integrated systems.
